**# Fan Monitor**



**Программа для мониторинга вентиляторов в Windows.**



**## Возможности**



**- Чтение показаний вентиляторов с помощью LibreHardwareMonitorLib.**

**- Определение состояния: ON при скорости больше 0 RPM, OFF при 0 RPM.**

**- Запись состояния в текстовый файл каждые 5 минут.**

**- Фоновый запуск при включении Windows через Планировщик заданий.**



**## Датчики на тестовом компьютере**



**- Fan 1 — CPU Fan.**

**- Fan 2 — System Fan #1.**

**- Fan 3 — GPU Fan 1.**

**- Fan 4 — GPU Fan 2.**



**Названия датчиков заданы для тестового компьютера. На другом ПК их может потребоваться изменить в Program.cs.**
